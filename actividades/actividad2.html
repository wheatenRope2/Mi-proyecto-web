Explicando Código de C en HTML


    #include <stdio.h>

    int main() {
        int edad;
        printf("Introduce tu edad: ");
        scanf("%d", &edad);

        if (edad >= 18) {
            printf("Eres mayor de edad.\n");
        } else {
            printf("Eres menor de edad.\n");
        }
        return 0;
    }

En la linea #include <stdio.h>
Nos ayuda a incluir la librería estándar de entrada y salida en C

En la linea int main()
Es la función principal del programa, y el int significa que la función nos va a regresar un entero

En la linea int edad;
Se crea una variable de tipo entera, lo cual significa que almavenara solo números enteros

En la linea printf("Introduce tu edad: ");
Muestra el texto entre comillas en la pantalla

En la linea scanf("%d", &edad);
Sirve para capturar datos por los usuarios. El "%d" indica que se leerá un número entero. Y el &edad guarda el numero dentro de la variable edad

En la linea if (edad >= 18)
Aqui el programa verifica una condición, donde se pregunta si es mayor de edad, con los operadores >= que significa mayor o igual que, en este caso si la edad es mayor o igual que 18

En la linea printf("Eres mayor de edad.\n");
En caso de que se verdad la condicion del if, nos va a imprimir el printf que esta dentro del if

En la linea else
Aqui se indica que en caso de que no se cumpla la condicón del if va a entrar al bloque del else

En la linea printf("Eres menor de edad.\n");
Por lo que si entra al else nos va a imprimir el printf de este mismo

En la linea return 0;
Indica un retorno de 0 a la funcion main, y cocluye el programa
